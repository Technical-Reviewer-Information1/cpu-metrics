# CPU性能指標可視化学習アプリ 💻

このアプリケーションは、CPUのビット数とクロック周波数がデータ処理能力と処理時間にどのように影響するかを視覚的に学習できるWebアプリケーションです。

## 🎯 機能

### 1. ビット数とデータ処理能力の可視化
- 32ビットと64ビットCPUの処理方式の違いを体験
- データが処理される様子をアニメーションで可視化
- 処理サイクル数と処理時間の比較

### 2. クロック周波数と処理速度のシミュレーション
- スライダーでクロック周波数を調整
- リアルタイムで処理時間の変化を確認
- 異なる周波数での性能比較グラフ

### 3. 性能比較と最適化
- CPU性能マトリックス（ヒートマップ）
- 実世界タスクでの性能比較
- 各種ワークロードでの最適化例

### 4. インタラクティブ学習
- **クイズ**: CPU性能に関する理解度チェック
- **性能計算器**: 仕様入力による性能予測
- **実験ラボ**: ワークロード別シミュレーション

### 5. まとめと考察
- 重要ポイントの整理
- 車との比較による直感的理解
- 性能予測ツール

## 🚀 実行方法

```bash
# 必要なパッケージをインストール
pip install -r requirements.txt

# アプリケーションを起動
streamlit run streamlit_app.py
```

アプリケーションが起動したら、ブラウザで `http://localhost:8501` にアクセスしてください。

## 🛠 技術仕様

- **フロントエンド**: Streamlit
- **可視化ライブラリ**: Plotly
- **データ処理**: Pandas, NumPy
- **言語**: Python

## 📚 教育効果

- CPUの性能指標を体験的に理解
- ビット数とクロック周波数の影響を視覚化
- 実世界での性能差を具体的に把握
- コンピュータ選択時の指標として活用可能
